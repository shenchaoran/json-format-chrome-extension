JSON 节点格式化JSON Node Formatter

右键页面任意节点，一键格式化其中的 JSON：可折叠、可搜索、可编辑，支持校验、对比、JSONPath、值解码与类型生成。所有处理都在本地完成。

Right-click any element to turn its JSON into a collapsible, searchable, editable tree — with validation, diff, JSONPath, value decoding and type generation. Everything runs locally.
