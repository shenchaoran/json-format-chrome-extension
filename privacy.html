隐私政策

适用于 Chrome 扩展「JSON 节点格式化（JSON Formatter）」· 生效日期：2026-10-09

不收集任何数据

本扩展不收集、不上传、不出售、不与任何第三方共享你的个人信息、浏览记录或页面内容。扩展没有服务器，不包含任何统计、广告或追踪代码。

页面内容如何处理

只有当你主动操作（右键「格式化 JSON」、使用快捷键或点击工具栏图标）时，扩展才会读取你所选节点或选中文本中的内容，并且只在你的浏览器本地解析和显示。关闭标签页后这些内容即被丢弃。

当 JSON 中的值是图片链接时，鼠标悬停预览会由浏览器直接请求该图片地址（不带来源信息 Referrer）；扩展本身不会发起其它网络请求。

本地存储

扩展使用 chrome.storage.local 在你的设备上保存：设置项（语言、缩进、默认展开层级等）、面板宽度和位置。这些数据不会离开你的设备，卸载扩展后会被一并删除。

权限说明

  • contextMenus：在右键菜单中添加「格式化 JSON」。
  • storage：在本地保存上述设置与面板布局。
  • scripting / activeTab：你通过右键菜单、快捷键或工具栏图标操作时，在当前标签页显示格式化面板、读取选中的文本。
  • 在所有网站上运行的内容脚本：JSON 可能出现在任何网页（接口调试页、日志平台、后台系统等），需要在页面中记录右键位置、高亮源节点并显示面板。内容脚本不会自动读取或上传页面内容。

赞助

设置页中的收款码仅为图片，扫码付款在支付宝 / 微信等第三方 App 中完成，扩展不处理任何支付信息。

Privacy Policy

For the Chrome extension "JSON Formatter" · Effective date: 2026-10-09

No data collection

This extension does not collect, transmit, sell or share any personal information, browsing history or page content. It has no server and contains no analytics, advertising or tracking code.

How page content is handled

Only when you explicitly act (the "Format JSON" context menu item, a keyboard shortcut, or the toolbar icon) does the extension read the selected element or selected text. The content is parsed and displayed locally in your browser and discarded when the tab is closed.

When a JSON value is an image URL, hovering it lets the browser load that image directly (without a referrer). The extension makes no other network requests.

Local storage

The extension uses chrome.storage.local to store, on your device only, your settings (language, indent, default depth, etc.) and panel width and position. This data never leaves your device and is removed when the extension is uninstalled.

Permissions

  • contextMenus: adds the "Format JSON" item to the right-click menu.
  • storage: saves the settings and panel layout locally.
  • scripting / activeTab: shows the panel in the current tab and reads the selected text when you use the context menu, a shortcut or the toolbar icon.
  • Content scripts on all sites: JSON can appear on any page (API consoles, log viewers, admin tools), so the extension needs to remember where you right-clicked, highlight the source element and render the panel. Content scripts never read or upload page content on their own.

Donations

The QR codes on the settings page are static images. Payments happen entirely inside third-party apps (Alipay / WeChat Pay); the extension handles no payment information.
